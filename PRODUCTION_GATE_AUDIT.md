## Newly connected, limited workflows

The RAID Reconstruction route produces read-only-derived packages for operator-configured RAID 0, byte-identical RAID 1, full-member RAID 5, and full-member Linux MD left-symmetric RAID 6. RAID 5 supports Linux MD left-asymmetric, right-asymmetric, left-symmetric, and right-symmetric rotating layouts. RAID 6 supports only left-symmetric rotating P/Q; the Q syndrome follows Linux MD's reverse coefficient order. Start and publish audit events and manifests record the selected parity mapping, and parity mismatches fail closed. Matching parity alone does not prove the selected data order or array layout; operators must validate against array metadata and independent file references. If image data has been written, failed output is retained and the job flushes and verifies its incomplete marker alongside the staging path. Degraded or missing-member reconstruction is not supported. The workflow requires an audited active case and explicit member order/data offset/sector geometry/stripe size, hashes members before and after reconstruction, rereads and hashes the output, publishes without replacing an existing package, registers the image as evidence, and records outcomes in the audit chain. Duplicate member paths are rejected by canonical path and opened-file identity, including Windows hard links; the regression verifies rejection before output staging. RAID 6 streams member ordering to avoid a per-stripe allocation. Synthetic tests cover RAID 0 ordering/package verification, RAID 1 matching and mismatch rejection, all four RAID 5 mappings, RAID 6 P/Q ordering over rotating parity rows, parity mismatch rejection with marked unverified staging, hard-link duplicate rejection, progress accounting, and cancellation cleanup. Linux MD reference coverage exists for RAID 5 left-symmetric only; RAID 6 still requires an independently generated MD array and exact-byte comparison. Vendor metadata detection, degraded arrays, broad layout coverage, and physical-array qualification remain open; RAID reconstruction is not production-qualified.
